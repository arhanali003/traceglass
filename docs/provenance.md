# Provenance

The starting reference for this project was the user-supplied `reverse-engineer-anything` skill, identifying itself as REA version 42 and linking to [morluto/rea](https://github.com/morluto/rea).

Traceglass's instructions and examples were separately authored around a narrower portable investigation workflow. Its name, visual identity, installer, fixture, and repository documentation were created for this project. The upstream skill and its reference files are not redistributed here. Evidence-first reporting and the optional integration are explicitly credited to REA; Traceglass does not claim to have invented REA's analysis capabilities.

REA tool names appear only as interoperability references. REA remains independently maintained and retains its own licensing. No affiliation or endorsement is implied by references to REA or supported agent clients.
